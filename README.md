# Tanvi Patel — Portfolio

A responsive developer portfolio featuring an introduction, skills, project case studies, and contact links.

## Built With

- React and Vite
- JavaScript
- CSS Modules and responsive CSS
- React Router

## Featured Projects

- **HealthyTrack:** Full-stack health and nutrition platform built with React, Node.js, Express, and MongoDB.
- **Farm Fusion:** Agricultural marketplace built with React, PHP, MySQL, and Bootstrap.

## Run Locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
